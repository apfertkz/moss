# Админ-панель MOSS SALE — план работ

Утверждено: веб-панель, три колонки (меню слева, список в центре, карточка
справа), вход по паролю с одноразовым кодом в Telegram.

## Где живёт

Внутри того же сервиса на Railway, в процессе бота. Отдельный деплой не нужен:
база уже рядом, домен выдаётся кнопкой в настройках сервиса.

- Бэкенд — aiohttp поверх текущей базы, JSON-интерфейс под `/api/*`
- Фронт — React + Vite + Tailwind, тёмная палитра сайта, собирается в статику
- Вход — пароль из переменной окружения плюс одноразовый код в Telegram,
  сессия в подписанной куке на 30 дней

## Этап 1. Фундамент в боте  ← делается первым

Без этого панель показывает сломанное.

1. **Продление подписки.** Период сбрасывается сам при наступлении новой
   даты, а не по чужому вызову. Функции продления, смены тарифа, добавления
   мест и пакетов тренировок.
2. **Тренировка переживает перезапуск.** Сейчас сессии лежат в памяти
   процесса: деплой — и менеджер пишет в пустоту. Переносим в базу.
3. **Повторы при сбоях Anthropic.** Одна сетевая ошибка не должна обрывать
   тренировку.
4. **Уведомления владельцу продукта.** Ошибки, истекающие подписки,
   аномальный расход — в личку, а не в логи Railway.
5. **Напоминания клиенту.** За 7, 3 и 1 день до конца подписки.

## Этап 2. Панель: каркас, обзор, клиенты

- Веб-сервер, вход, сессии, журнал действий
- Раскладка: меню / список / карточка, общий поиск сверху
- Обзор: деньги, активные компании, тренировки, расход и маржа;
  три списка «требует действия» — истекает, застряли на брифе, не тренируются
- Клиенты: фильтры, карточка, все действия кнопками

## Этап 3. Пользователи, демо, деньги

- Пользователи: поиск, карточка, отключение, роль, перенос,
  просмотр последней тренировки целиком
- Демо: очередь гостей с сайта, кнопка «выдать пилот»
- Деньги: расход по клиентам, себестоимость тренировки, маржа, аномалии

## Этап 4. Отчёты и рассылка

- Сводки за период, выгрузка в таблицу, отчёт для клиента файлом
- Рассылка: сегменты, предпросмотр, тест себе, отправка пачками с паузой,
  отчёт о доставке
- Тарифы и цены правятся из панели, без деплоя
- Выгрузка базы

## Что нужно от владельца продукта

- Нажать в Railway кнопку генерации домена для сервиса
- Задать переменную `ADMIN_PASSWORD`
- Убедиться, что реплика сервиса одна: бот работает на опросе Telegram,
  две копии начнут драться за обновления
