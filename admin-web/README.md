# Панель управления — интерфейс

React + Vite + Tailwind. Собирается в статику, которую отдаёт сам бот
из `static/admin`. Отдельный хостинг не нужен.

## Сборка

```bash
cd admin-web
npm install
npm run build
cp -r dist/* ../static/admin/
```

## Разработка

```bash
npm run dev        # http://localhost:5210
```

Запросы к `/api` уходят на `localhost:8080` — поднимите там бота
с заданным `PORT=8080`, и панель будет работать на живых данных.

## Что где

| Файл | Что внутри |
|------|------------|
| `src/App.tsx` | каркас: меню слева, список в центре, карточка справа |
| `src/api.ts` | обращения к серверу и типы ответов |
| `src/format.ts` | деньги, даты, склонения |
| `src/ui.tsx` | кнопки, поля, метки, плитки показателей |
| `src/sections/` | разделы панели |
