# CRM · crm.aisaty.com

Мини-CRM внутри панели. Не отдельный сервис: тот же процесс, та же база —
лиды, тарифы, компании и оплаты общие с админкой. Ничего не вбивается дважды.

## Что умеет

- **Лиды заводятся сами.** Гость прошёл демо на сайте и оставил контакт —
  лид появляется в колонке «Новые», менеджерам тут же стучит бот: имя,
  контакт, ниша, чем кончился демо-диалог и разбор.
- **Канбан.** Новые → В работе → Думают → Пилот → Оплатили → Отказ.
  Перетаскивание карточек, у карточки — заметка, ответственный, тариф, срок.
- **Карточка клиента.** Кнопки «Позвонить» / WhatsApp / Telegram из контакта.
  Видно демо-разбор лида — менеджер звонит подготовленным.
- **Выдать пилот** — создаёт компанию тем же tenancy, что и админка, и шлёт
  ссылку активации (или кладёт в буфер). Карточка дальше сама показывает,
  сколько тренировок компания провела и до какого числа доступ.
- **Пилот пошёл.** Как только компания лида провела первую тренировку —
  уведомление в бот: «лучший момент для звонка».
- **Счёт** — собирается из тарифов и цен по срокам (те же plans/plan_prices,
  что в админке), копируется одной кнопкой.
- **Оплачено** — продлевает подписку компании и пишет поступление в payments.
  Выручка в админке сходится сама.
- **Команда** — владелец добавляет менеджеров по Telegram ID. Менеджер входит
  по коду из бота, получает уведомления. ADMIN_IDS — владельцы всегда.
- **CSV** — выгрузка всех лидов одной кнопкой.

## Файлы

- `trainer/crm.py` — весь бэкенд (таблицы crm_users / crm_leads создаёт сам).
- `static/crm/` — интерфейс (ваниль, без сборки).
- Правки: `webadmin.py` (подключение + пропуск /api/crm/ в страже + отдача
  CRM на поддомене), `webdemo.py` (авто-лид после демо с контактом).

## Запуск (один раз)

1. **Пуш** репозитория moss — Railway задеплоит сам.
2. **Домен:** Railway → сервис панели → Settings → Networking →
   Custom Domain → `crm.aisaty.com`. У регистратора — CNAME `crm` на значение,
   которое покажет Railway (так же, как делали panel.aisaty.com).
3. **Переменные (по желанию):**
   - `CRM_INVOICE_DETAILS` — реквизиты для текста счёта (многострочно).
   - `CRM_URL` — если адрес не crm.aisaty.com.
4. Открыть crm.aisaty.com → ввести свой Telegram ID → код придёт в бот.

Пока домен не подключён, CRM доступна и по адресу `panel.aisaty.com/crm`.

## Проверка после деплоя

1. Пройти демо на сайте, оставить контакт → в боте пришло «Новый лид»,
   карточка появилась в «Новых».
2. Открыть карточку → «Выдать пилот» → ссылка активации скопировалась.
3. Активировать компанию в боте, провести тренировку → пришло «Пилот пошёл»,
   на карточке появился счётчик тренировок.
4. «Счёт» → текст с суммой по тарифу. «Оплачено» → в админке, раздел «Деньги»,
   появилось поступление.
